# همة المدينة العقارية — النسخة النهائية

هذه الحزمة تحتوي على النسخة المحدثة من الموقع الثابت، وتشمل التصميم المتجاوب، الترجمة العربية والإنجليزية، نموذج التقييم الذكي، فلترة المدن والأحياء، حاسبة التمويل العقاري، ونماذج العقود السكنية والتجارية.

## الملفات الرئيسية

| الملف | الوظيفة |
|---|---|
| `index.html` | الصفحة الكاملة للموقع وجميع الأقسام والنماذج. |
| `residential-contract-pdf.js` | توليد العقد السكني فوق قالب PDF الأصلي. |
| `commercial-contract-pdf.js` | توليد العقد التجاري فوق قالب PDF الأصلي. |
| `residential-contract.pdf` | قالب العقد السكني الأصلي، وعدد صفحاته 9. |
| `commercial-contract.pdf` | قالب العقد التجاري الأصلي، وعدد صفحاته 9. |
| `Himmat-Almedina.png` | شعار المنشأة المستخدم في الموقع. |

## طريقة الرفع

ارفع جميع الملفات الرئيسية إلى جذر مستودع GitHub Pages نفسه. يجب أن تكون ملفات `index.html` وملفا JavaScript وقالبا PDF في المجلد نفسه. يعتمد توليد PDF على مكتبات `pdf-lib` و`fontkit` المحملة من CDN؛ لذلك يلزم اتصال بالإنترنت عند إنشاء العقد.

## المزايا المضافة

يحتوي نموذج التقييم على ست خطوات، مع بحث قابل للفلترة للمدن والأحياء، وتحديث تلقائي لقائمة الأحياء بعد اختيار المدينة. كما أضيفت حاسبة تمويل عقاري تقدر الدفعة الأولى ومبلغ التمويل والقسط الشهري وإجمالي الأرباح والسداد، ويمكنها استخدام نتيجة التقييم مباشرة.

صفحة «عن المكتب» تتضمن الرؤية والرسالة، وجميع الأقسام الأساسية مدعومة بالعربية والإنجليزية، بما في ذلك القيم الديناميكية في ملخص التقييم ورسالة واتساب.

## تنبيه العقود

مولدات العقود الحالية تستخدم قوالب PDF ثابتة وتكتب البيانات فوقها بعد تغطية مناطق محددة. الإحداثيات الحالية هي أساس للمعايرة، ويجب مراجعة الناتج بصرياً على الصفحات التسع. المخرجات الآلية مسودات للمراجعة وليست بديلاً عن العقد الرسمي أو المراجعة القانونية.

## الختم والتوقيع

يمكن إضافة صورة ختم PNG شفافة إلى الصفحة الأخيرة عبر نفس خريطة الإحداثيات. أما التوقيع الإلكتروني المعتمد فيحتاج تكاملاً مع مزود توقيع وهوية موثوق، ولا يكفي رسم صورة توقيع داخل PDF لإثبات الاعتماد القانوني.
