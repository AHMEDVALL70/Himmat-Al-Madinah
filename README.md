# نسخة همة المدينة المطوّرة

## ما تم تحسينه

تم تحويل نموذج التقييم العقاري من نموذج طويل إلى تجربة من ست خطوات: هدف التقييم، موقع العقار، نوع العقار، المواصفات الأساسية، المزايا الإضافية، ثم مراجعة البيانات والنتيجة.

تمت إضافة شريط تقدم، بطاقات اختيار لأنواع العقار، تحقق من المساحة، ملخص قبل الحساب، رسالة توضيحية عن طبيعة النتيجة، وزر واتساب برسالة تلقائية تتضمن بيانات التقييم.

## طريقة الاستخدام

ضع الملفين `index.html` و`Himmat-Almedina.png` في نفس مجلد الموقع. استبدل ملف `index.html` الحالي بالنسخة الموجودة هنا، ثم ارفع التغييرات إلى مستودع GitHub Pages.

## ملاحظة مهمة

منطق الحساب الحالي تقديري وتجريبي داخل JavaScript. إذا كانت النتائج ستستخدم كتقييم رسمي أو لاتخاذ قرارات مالية، يجب ربطه ببيانات سوق موثوقة ومراجعة المعادلات من مختص عقاري.
