# همة المدينة العقارية — النسخة المحسنة

هذه نسخة محسنة من الصفحة الثابتة لموقع همة المدينة العقارية، مع الحفاظ على وظائف التقييم والعروض والعقود والإضافة والتواصل.

## ما تم تحسينه

تم توحيد نظام الألوان والخلفيات والبطاقات والأزرار والأيقونات في جميع الصفحات. كما تم تقليل الفراغات غير الضرورية في الصفحات القصيرة، وتحسين المسافات في بطاقات العروض والخدمات والأسئلة، وإضافة تخطيط متجاوب للشاشات الصغيرة.

تم إكمال الترجمة الإنجليزية لصفحة About، الأسئلة الشائعة، العروض، الخدمات، العقود، الإضافة، ونموذج التقييم. كما أصبحت القيم الديناميكية داخل ملخص التقييم ورسالة واتساب تتغير حسب اللغة المختارة.

تم تحسين نموذج التقييم إلى تجربة من ست خطوات مع شريط تقدم، خيارات أوضح، مراجعة قبل الحساب، نتيجة منظمة، وزر تواصل مع خبير عبر واتساب. كما تم تصحيح بعض التسميات غير الواضحة مثل Reviews بدلاً من Rating %.

## طريقة الرفع إلى GitHub Pages

استبدل ملف `index.html` في مستودع GitHub بالملف الموجود هنا، وارفع معه `Himmat-Almedina.png` وملفي العقود في جذر المستودع نفسه. بعد الحفظ، انتظر تحديث GitHub Pages ثم افتح رابط الموقع في نافذة خاصة أو نفّذ تحديثاً قسرياً للمتصفح.

لا تغيّر أسماء الملفات أو مساراتها ما لم تعدل المراجع داخل `index.html`. تم اختبار النسخة محلياً، والتنقل بين خطوات التقييم والحساب واللغة الإنجليزية، ولم يظهر أي خطأ JavaScript في سجل المتصفح.
